#  Responsive Landing Page

A sleek, modern **landing page** built with HTML, CSS, and JavaScript.  
Includes a **fixed navigation bar** that changes style on scroll and a **dynamic animated background**.

---

##  Features

-  Fixed navigation bar
-  Navigation bar changes background color on scroll
-  Hover effects on nav menu items
-  Animated gradient background for hero section
-  Fully responsive layout
-  Scrollable content with smooth structure

## Built With
HTML5

CSS3 – Flexbox, Media Queries, Keyframe Animations

JavaScript (Vanilla) – Scroll interaction
